# Geist and Geist Mono

Geist v1.7.2 (https://github.com/vercel/geist-font, release `v1.7.2`), the static TTFs
Regular, Medium and SemiBold of Geist and Regular of Geist Mono, copied unmodified and
embedded in the paintnotnet binary as the UI typeface.
