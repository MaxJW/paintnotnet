# Lucide icons

The UI's icons are Lucide 1.48.0 (https://lucide.dev, https://github.com/lucide-icons/lucide,
release `1.48.0`), copied unmodified from the release's `lucide-icons-1.48.0.zip`. Only the
icons paintnotnet uses are here. They are embedded in the binary and rasterised at run time,
recoloured to the theme (the SVGs use `currentColor`).
